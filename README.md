# MyContacts App

A simple Java console application to manage contacts.  
This project is built using basic Object-Oriented Programming (OOP) concepts.

---

## Project Goal

The goal of this app is to help users:

- Register and login
- Create and manage contacts
- Edit and delete contacts
- Group and search contacts

---

## Use Cases

### UC-01: User Registration
User creates a new account with email, password, and basic profile details.

### UC-02: User Login
Registered user logs in using email and password.

### UC-03: Profile Management
User updates profile info such as name, password, and preferences.

### UC-04: Create Contact
User adds a new contact (Person or Organization) with phone and email.

### UC-05: View Contact Details
User views full details of a selected contact.

### UC-06: Edit Contact
User updates existing contact information.
